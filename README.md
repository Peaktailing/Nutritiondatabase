## 二、数据表说明

### 1. 主营养表(`food_nutrition`)
每 100g 可食部的营养成分,两册共 **1810 条**。

| 分类 | 条数 | 分类 | 条数 |
|---|---|---|---|
| 畜禽肉及制品 | 479 | 谷薯类 | 105 |
| 蔬菜类 | 310 | 豆类及豆制品 | 79 |
| 鱼虾蟹贝类 | 244 | 菌藻类 | 66 |
| 乳类及制品 | 192 | 坚果、种子类 | 64 |
| 水果类 | 175 | 薯类及淀粉制品 | 26 |
| 蛋类及制品 | 26 | 油脂类 | 24 |

字段:食部、水分、能量(kcal/kJ)、蛋白质、脂肪(含饱和/单不饱和/多不饱和)、
碳水化合物、膳食纤维、胆固醇、灰分、维生素 A/β-胡萝卜素/B1/B2/烟酸/C/E、
钙、磷、钾、钠、镁、铁、锌、硒、铜、锰、碘。

### 2. 附录表

| 表 | 条数 | 单位 | 内容 |
|---|---|---|---|
| 氨基酸 | 856 | mg/100g(USDA 版为 g/100g) | 异亮/亮/赖/蛋/胱/苯丙/酪/苏/色/缬氨酸等,含 SAA、AAA 合计 |
| 脂肪酸 | 972 | g/100g | SFA/MUFA/PUFA 及 4:0~22:6 各碳链脂肪酸,含 EPA、DHA |

### 3. 四表关联覆盖率
以主表 1810 条为基准:氨基酸 44%、脂肪酸 35%、样品描述 40%。
其余为原书本来未收录该食物的对应数据,非缺失。

## 三、数据质量

校验结果(1810 条):

| 等级 | 条数 | 占比 | 说明 |
|---|---|---|---|
| A 可信 | 1534 | 85% | 无越界、守恒关系成立 |
| B 基本可信 | 222 | 12% | 轻微问题(如个别字段缺失) |
| C 需核对 | 54 | 3% | 存在越界或守恒失守 |
| D 可疑 | 0 | 0% | — |

**零重复编码。**

### 使用建议
主表带 `macro_sum`(六大宏量合计)与 `check_grade` 字段:
- `macro_sum` 在 **94~106** → 数据可信
- 偏离较大 → 该记录可能有个别数值识别不准,建议比对原书

> 营养学数值本身有测量误差,叠加 OCR 识别,**关键数据请交叉核对原书**。

## 四、USDA 兼容版说明

在原始库基础上新增 USDA FoodData Central 惯用命名列,原始中文列全部保留。

- 主表新增 **33 列**:`Energy (kcal)`、`Total lipid (fat)`、
  `Carbohydrate, by difference`、`Fiber, total dietary`、`Calcium, Ca`、
  `Vitamin A, RAE` 等
- 氨基酸 **20 列**:由 mg/100g 换算为 **g/100g**(USDA 惯用单位)
- 脂肪酸 **28 列**:含 `20:5 (EPA)`、`22:6 (DHA)`
- 提供 `v_full` 视图(87 列):四表一键联查

```sql
-- 示例:联查主表 + 氨基酸 + 脂肪酸 + 样品描述
SELECT ndb_number, food_name, "Energy (kcal)", "Protein",
       "aa_Leucine", "fa_Fatty acids, total saturated", sampling_place
FROM v_full
WHERE aa_Leucine IS NOT NULL;
```

### 合并 USDA 时注意
USDA 的 `Carbohydrate, by difference` 是「减差法」计算值,
与中国食物成分表的碳水化合物定义略有差异,合并时留意口径。

## 五、数据来源与局限

- 来源:《中国食物成分表 标准版 第6版》(两册扫描版)
- 方式:RapidOCR 逐页识别 → 表类型判定 → 表头模板对齐 → 列映射 →
  物理约束校验与修正 → 跨页合并
- 已排除附录表(氨基酸/脂肪酸/样品描述)对主表的污染
- 11 页为空白 Notes 页,无数据

**已知局限**:
1. 扫描件 OCR 存在个别数值误差(已用质量守恒、能量守恒、kJ/kcal 一致性
   三重约束修正,但仍可能残留)
2. 第二册守恒通过率 55%,低于第一册 78% —— 主要因动物性食物常缺
   「碳水化合物」列(含量本就为 0),导致合计偏低,而非数据错误
3. 原书部分数值带符号标记:`Tr`(未检出)、`*`(参考值)、
   `—`(未检测)、`un`(不能计算)

## v2 更新：新增 volume（册次）字段

四张表（food_nutrition / sample_desc / amino_acid / fatty_acid）均已添加 `volume` 列，标注数据来自第几册。附录三个 CSV 同步添加"分册"列。

**分册判定规则**（以原书两册实际页面归属为准）：

| food_code 前两位 | 分册 | 说明 |
|---|---|---|
| 01~07 | 第一册 | 植物性食物（谷薯、豆类、蔬菜、菌藻、水果、坚果） |
| 08~13 | 第二册 | 动物性食物（畜禽肉、乳蛋、鱼虾蟹贝） |
| 19 且段位 1910 | 第二册 | 动物油脂（猪油/羊油/鸭油等） |
| 19 且段位 1920/1921/1922 | 第一册 | 植物油脂（通用油/品牌油/进口橄榄油） |
| 21 | 第二册 | 其他（药食两用等） |

- 主表 1810 行 100% 定册（第一册 844 / 第二册 966），以原始两个营养 CSV 的逐行拆分为硬依据
- 附录三表优先按主表映射，油脂类按段位规则，仅 amino_acid 表 3 个 OCR 异常编码（161101/601180/801111）无法判定留空
- `meta` 表 `volume_mapping` 条目记录完整规则
